## Что получится

Привычка сохранять состояние проекта перед правкой — и умение вернуться к любому из сохранений.

## Зачем

Claude меняет файлы быстро и помногу. Через час работы вы не вспомните, что было в начале. Сохранение — это
снимок всей папки с подписью: «страница работает, калькулятор ещё не добавлен».

У программистов для этого есть инструмент — git. Командовать им не нужно: это делает Claude.

## Шаги

### 1. Включите сохранения

Если папку вы уже [[kak-vylozhit-stranicu|выложили через Claude]], сохранения в ней включены — переходите ко второму
шагу. Иначе один раз для каждой папки:

```
Включи в этой папке сохранения через git. Если git не установлен — объясни, как поставить, и спроси разрешения.
Сделай первое сохранение с подписью «начало».
Файл .env и всё, где лежат ключи и пароли, в сохранения не включай.
```

### 2. Сохраняйте перед правкой

Перед каждой правкой, после которой может стать хуже:

```
Сохрани текущее состояние с подписью «страница готова, перед калькулятором».
```

Подпись пишите для себя через месяц: что работает и что собираетесь делать.

### 3. Посмотрите, что есть

```
Покажи список сохранений: дата и подпись.
```

### 4. Вернитесь назад

```
После последних правок стало хуже. Верни папку в состояние сохранения «страница готова, перед калькулятором».
Сначала скажи, какие изменения при этом пропадут, и спроси подтверждения.
```

Вторая строка обязательна: возврат стирает всё, что сделано после сохранения.

## Правило

**Работает — сохрани.** Не «закончил — сохрани», а именно «работает». Тогда каждое сохранение — место, куда не
страшно вернуться.

## Чего сохранения не дают

Они лежат в той же папке на том же компьютере. Сломался компьютер — пропали и они. Копия на [[kak-vylozhit-stranicu|GitHub]] эту проблему
решает: каждое «выложи» отправляет туда и ваши сохранения — см. [[kak-pravit-posle-vykladki|Как править после выкладки]].

## Если не получилось

- **Claude говорит, что есть несохранённые изменения.** Он спрашивает, что с ними делать. Если не уверены —
  сначала сохраните их с подписью «на всякий случай», потом возвращайтесь.
- **Не помните, какое сохранение нужно.** Попросите: «покажи, чем сохранение „…“ отличается от текущего
  состояния, обычными словами».
