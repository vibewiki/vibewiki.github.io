## Что получится

Сайт открывается по вашему адресу — например, `ivanov-accounting.ru` — и по защищённому соединению.

## Что нужно

- выложенный сайт и Claude с доступом к вашему GitHub — см. [[kak-vylozhit-stranicu|Как выложить страницу]];
- несколько сотен рублей на год;
- терпение: после настройки адрес начинает работать не сразу, иногда через сутки.

## Шаги

### 1. Купите адрес

Адрес покупают у регистратора — компании, которая ведёт учёт адресов. Регистраторов много, условия похожи;
например, [REG.RU](https://www.reg.ru/) — один из крупнейших в России. На сайте регистратора введите желаемое имя
в строку поиска, проверьте, свободно ли оно, и оплатите на год.

Выбирайте короткое имя, которое можно продиктовать по телефону без уточнений.

### 2. Попросите Claude подключить адрес

Откройте папку сайта в VS Code, откройте Claude и напишите — со своим адресом вместо `ivanov-accounting.ru`:

```
Я купил адрес ivanov-accounting.ru. Подключи его к моему сайту на GitHub Pages.

1. Впиши этот адрес в настройки Pages репозитория site через gh.
2. Напиши, какие записи мне добавить в DNS у регистратора, таблицей: тип, имя, значение.
   Нужен и сам адрес, и адрес с www.

Перед каждым шагом, который что-то меняет на GitHub, коротко скажи, что делаешь, и спроси разрешения.
```

Адрес вписывается в GitHub раньше, чем у регистратора: так никто другой не успеет привязать его к своему сайту.

### 3. Внесите записи у регистратора

Это Claude за вас не сделает: записи меняются в личном кабинете регистратора, под вашим входом. Найдите там
раздел управления DNS — это таблица, которая говорит интернету, где лежит ваш сайт, — и добавьте строки, которые
дал Claude. В REG.RU он в списке ваших доменов: откройте купленный адрес и найдите управление зоной. Для GitHub Pages они такие:

| Тип | Имя | Значение |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | your-name.github.io |

В последней строке вместо `your-name` — ваше имя пользователя на GitHub. Если в таблице уже есть записи типа A
с другими значениями, удалите их.

Кабинет регистратора выглядит иначе, чем вы ожидали? Сделайте снимок экрана и покажите Claude: «мне нужно добавить
такие записи, вот что я вижу, куда нажимать?»

Когда внесёте, попросите проверить:

```
Я добавил записи у регистратора. Проверь, что адрес и адрес с www смотрят туда, куда нужно.
Если где-то ошибка — скажи, какую строку исправить.
```

Claude проверит записи сам и укажет на опечатку, если она есть. Если записи ещё старые — это не ошибка: новые
расходятся по интернету от нескольких минут до суток.

### 4. Попросите включить защиту

Через несколько часов напишите:

```
Проверь, видит ли GitHub мой адрес и готова ли защита HTTPS. Если готова — включи
«Enforce HTTPS» и скажи, по какому адресу теперь открывается сайт.
```

Защиту GitHub выпускает сам, но только после того, как увидел адрес. Если Claude скажет «ещё не готово» —
спросите снова позже. Когда она включена, сайт открывается по защищённому соединению, без «небезопасно» в
браузере.

## Если не получилось

- **Прошли сутки, адрес не работает.** Попросите Claude: «проверь записи моего адреса и настройки Pages и скажи,
  что не так».
- **Сайт открывается, но браузер пишет «небезопасно».** Защита ещё не включена. Повторите запрос из шага 4.
- **По адресу с www не открывается.** Не добавлена строка CNAME — Claude это увидит при проверке из шага 3.

## Что важно знать

Адрес оплачивается каждый год. Если не продлить, сайт перестанет открываться, а адрес через время сможет купить
кто-то другой. Поставьте напоминание.
