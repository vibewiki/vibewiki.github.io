## Что получится

Страница с адресом вида `https://your-name.github.io/site/`, которая открывается у любого человека с любого
устройства. И Claude, который дальше выкладывает каждую правку сам — по слову «выложи».

## Что нужно

- папка с готовой страницей — см. [[stranica-o-svoem-dele|Страница о своём деле]];
- почта для регистрации;
- полчаса.

## Что такое GitHub

Сайт, где хранят файлы проектов. Папка с файлами там называется репозиторием. Одна из его возможностей — показывать
файлы из такой папки как сайт. Она называется Pages и для открытых репозиториев бесплатна.

## Шаги

### 1. Заведите учётную запись

Это единственное, что Claude за вас не сделает: регистрация проверяет, что вы человек.

1. Откройте `github.com` и нажмите «Sign up».
2. Введите почту, придумайте пароль и **имя пользователя** — оно попадёт в адрес сайта. Выберите короткое,
   латиницей: `ivanova-buh`, а не `user-48213`.
3. GitHub пришлёт на почту код — введите его.
4. Если спросят про тариф, оставьте бесплатный (Free).

Пароль от GitHub держите у себя. Claude он не нужен: доступ вы дадите ему на следующем шаге другим способом.

### 2. Дайте Claude доступ

Откройте папку сайта в VS Code, откройте Claude и напишите:

```
Мне нужно выкладывать эту папку на GitHub через тебя. Я не программист.

1. Проверь, установлены ли на компьютере git и GitHub CLI (программа gh).
   Если чего-то нет — объясни, что поставишь, и спроси разрешения.
2. Войди в мой GitHub через gh, способом с кодом в браузере. Запусти вход в фоне,
   покажи мне одноразовый код и адрес, куда его ввести, и жди, пока я подтвержу.
   Пароль от GitHub я тебе писать не буду.
3. Когда я напишу «готово», проверь, что вход прошёл, и скажи, под каким именем ты вошёл.
```

Claude покажет код из восьми знаков, вроде `BDE9-2ED4`, и адрес `github.com/login/device`. Дальше:

1. Откройте этот адрес в браузере — там, где вы вошли в GitHub.
2. Введите код и нажмите «Continue».
3. GitHub спросит, разрешить ли доступ **GitHub CLI**. Нажмите «Authorize GitHub CLI».
4. Вернитесь в VS Code и напишите Claude «готово».

Код действует около пятнадцати минут. Не успели — попросите новый.

Если на компьютере нет git, на Mac может появиться окно с предложением установить инструменты разработчика.
Нажмите «Установить» и дождитесь конца: это программа от Apple, она нужна git.

### 3. Попросите выложить

```
Выложи эту папку как сайт на GitHub Pages.

- Включи в папке сохранения через git, если их ещё нет. Файл .env и всё, где лежат ключи и пароли,
  в репозиторий не включай.
- Создай на GitHub открытый репозиторий site и отправь туда файлы папки.
- Включи для него GitHub Pages: ветка main, корень папки.
- Подожди, пока сайт откроется, и скажи его адрес.

Перед каждым шагом, который что-то меняет на GitHub, коротко скажи, что делаешь, и спроси разрешения.
```

Claude сам создаст репозиторий, отправит в него `index.html` и `photo.jpg` и включит Pages. Сайт появляется не
сразу — через одну-две минуты после включения.

### 4. Проверьте

Откройте адрес с телефона, не с компьютера: так вы увидите страницу глазами клиента. Нажмите обе кнопки.

## Что важно знать

**Всё, что в репозитории, видно всем.** Открытый репозиторий может прочитать любой человек. В нём должен быть
только сам сайт: ни документов, ни файлов с паролями. Поэтому в запросе прямо сказано про `.env`.

**Доступ, который вы дали, широкий.** Через вход в GitHub CLI Claude может создавать репозитории и отправлять
файлы во все ваши репозитории от вашего имени. Для учётной записи, где лежит один сайт, это нормально. Отозвать
доступ можно в любой момент: на GitHub — ваш значок справа вверху → «Settings» → «Applications» → вкладка
«Authorized OAuth Apps» → «GitHub CLI» → «Revoke».

## Если не получилось

- **Claude пишет, что вход не прошёл.** Код истёк или введён в другом браузере, где вы не вошли в GitHub.
  Попросите: «начни вход заново и покажи новый код».
- **По адресу «404».** Подождите пять минут. Если не помогло — спросите Claude: «проверь, включён ли Pages и
  лежит ли index.html в корне репозитория».
- **Страница есть, картинки нет.** Фото не попало в репозиторий или названо иначе, чем на странице. Большие и
  маленькие буквы в именах здесь различаются: `Photo.jpg` и `photo.jpg` — разные файлы. Спросите Claude: «какие
  файлы лежат в репозитории?»
- **Claude не может включить Pages.** Включите сами: в репозитории на GitHub «Settings» → слева «Pages» → в
  «Branch» выберите `main` и папку `/ (root)` → «Save».
