## Что получится

Страница с адресом вида `https://your-name.github.io/site/`, которая открывается у любого человека с любого
устройства.

## Что нужно

- папка с готовой страницей — см. [[stranica-o-svoem-dele|Страница о своём деле]];
- почта для регистрации;
- полчаса.

## Что такое GitHub

Сайт, где хранят файлы проектов. Папка с файлами там называется репозиторием. Одна из его возможностей — показывать
файлы из такой папки как сайт. Она называется Pages и для открытых репозиториев бесплатна.

## Шаги

### 1. Заведите учётную запись

На `github.com` нажмите «Sign up». Имя пользователя попадёт в адрес сайта — выберите короткое, латиницей.

### 2. Создайте репозиторий

1. Нажмите «+» вверху справа → «New repository».
2. Название — латиницей, например `site`. Оно тоже попадёт в адрес.
3. Отметьте **Public**: в бесплатной учётной записи сайт показывается только из открытого репозитория.
4. Нажмите «Create repository».

### 3. Загрузите файлы

1. На странице пустого репозитория нажмите ссылку «uploading an existing file».
2. Перетащите в окно **содержимое** папки сайта: `index.html` и изображения. Не саму папку, а то, что в ней.
3. Внизу нажмите «Commit changes».

Главный файл должен называться `index.html` — именно его GitHub показывает как страницу.

### 4. Включите сайт

1. В репозитории откройте «Settings» → слева «Pages».
2. В «Source» выберите «Deploy from a branch».
3. В «Branch» выберите `main` и папку `/ (root)`, нажмите «Save».

Через одну-две минуты наверху этой страницы появится адрес сайта.

### 5. Проверьте

Откройте адрес с телефона, не с компьютера: так вы увидите страницу глазами клиента. Нажмите кнопку связи.

## Что важно знать

**Всё, что вы загрузили, видно всем.** Открытый репозиторий может прочитать любой человек. Не загружайте туда
ничего, кроме самого сайта: ни документов, ни файлов с паролями.

## Если не получилось

- **По адресу «404».** Подождите пять минут. Если не помогло — проверьте, что файл называется `index.html` и лежит
  в корне репозитория, а не во вложенной папке.
- **Страница есть, картинок нет.** Изображения не загружены или названы иначе, чем на странице. Большие и
  маленькие буквы в именах здесь различаются: `Photo.jpg` и `photo.jpg` — разные файлы.
