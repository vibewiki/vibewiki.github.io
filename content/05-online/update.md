## Что получится

Правка на живом сайте — и уверенность, что версия у вас на компьютере и версия в интернете совпадают.

## Порядок

1. **Правите у себя.** Откройте папку сайта в [[chto-takoe-vs-code|VS Code]] и попросите Claude об изменении.
2. **Проверяете у себя.** Откройте `index.html` в браузере и посмотрите, что стало.
3. **Загружаете.** В репозитории на [[kak-vylozhit-stranicu|GitHub]]: «Add file» → «Upload files», перетащите изменённые файлы,
   «Commit changes». Файл с тем же именем заменит прежний.
4. **Проверяете на сайте.** Через минуту-две откройте адрес и обновите страницу.

## Почему не править прямо на GitHub

Там есть кнопка с карандашом, и текст можно поменять прямо в браузере. Для одной цифры это удобно. Но тогда версия
в интернете расходится с версией на вашем компьютере, и следующая загрузка сотрёт эту правку. Держитесь одного
направления: с компьютера — в интернет.

## Когда надоест загружать руками

Claude Code умеет отправлять изменения на GitHub сам: вы пишете «выложи», и через минуту сайт обновлён. Настроить
это один раз можно так:

```
У меня есть репозиторий на GitHub: [адрес репозитория]. В этой папке лежит сайт, который я загружал туда вручную.
Настрой так, чтобы ты мог отправлять изменения сам. Объясняй каждый шаг и спрашивай, прежде чем что-то
устанавливать.
```

Он попросит подтвердить в браузере, что это вы. Пароль от GitHub в разговор не пишите.

## Если не получилось

- **Сайт не изменился.** Браузер показывает сохранённую копию. Откройте страницу в режиме инкогнито или с другого
  устройства.
- **Изменилось не то.** Загрузили не тот файл. Загрузите нужный ещё раз: предыдущие версии GitHub хранит, ничего
  не потеряно.
