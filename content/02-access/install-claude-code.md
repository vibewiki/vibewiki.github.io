## Что получится

Программа, в которой слева лежат ваши файлы, а сбоку открыт разговор с Claude. Он видит эти файлы и может их
менять — с вашего [[chto-on-sprashivaet|разрешения]].

## Что нужно

- компьютер на macOS, Windows или Linux;
- оплаченная подписка Claude — см. [[kak-oplatit-podpisku|Как оплатить подписку]];
- пятнадцать минут.

## Шаги

### 1. Поставьте VS Code

VS Code — бесплатная программа для работы с файлами проекта. Скачайте её с сайта `code.visualstudio.com` и
установите как обычную программу. Что в её окне где — в материале
[[chto-takoe-vs-code|VS Code: что это и где в нём что]].

![Стартовая страница VS Code: заголовок Visual Studio Code, слева узкая полоса значков, в середине ссылки New File и Open](/media/shots/vscode-start.png)

*Так VS Code выглядит при первом запуске. Слева — узкая полоса значков: она понадобится на следующем шаге.*

### 2. Добавьте Claude Code

1. В левой полосе нажмите значок из четырёх квадратов — «Extensions», дополнения. Он пятый сверху.
2. В поиске наберите `claude`.
3. Выберите **Claude Code for VS Code**, у которого автор — **Anthropic** с синей галочкой. Это важно: ниже будут
   похожие названия и похожие значки от других авторов.
4. Нажмите «Install».

![Список дополнений по запросу claude: первым стоит Claude Code for VS Code от Anthropic с галочкой, ниже — похожие дополнения других авторов](/media/shots/vscode-poisk-dopolneniya.png)

*Нужное — первое в списке: оранжевая звёздочка, автор Anthropic с синей галочкой. Остальные сделаны другими людьми.*

![Страница дополнения Claude Code for VS Code: автор Anthropic, сайт anthropic.com, синяя кнопка Install](/media/shots/vscode-stranica-dopolneniya.png)

*Нажмите на дополнение — откроется его страница. Проверьте автора и нажмите синюю кнопку «Install».*

### 3. Откройте папку

Claude работает внутри одной папки и не видит остального компьютера.

1. Создайте пустую папку — например, `first` на рабочем столе.
2. В VS Code выберите «File → Open Folder» и укажите её.
3. На вопрос, доверяете ли вы авторам файлов в этой папке, ответьте «да»: папка ваша и пока пустая.

### 4. Откройте Claude и войдите

После установки вверху справа, над открытым файлом, появилась **оранжевая звёздочка**. Нажмите её — разговор с
Claude откроется вкладкой, рядом с файлами. Так удобнее всего: вкладка широкая, и её можно держать открытой.

![Окно VS Code с открытой пустой папкой first; вверху справа обведена оранжевая звёздочка — кнопка, которая открывает Claude](/media/shots/vscode-papka-i-zvezdochka.png)

*Папка `first` открыта и пока пуста. Обведена звёздочка, которая открывает Claude. Такой же значок появился и в
левой полосе — он открывает разговор узкой панелью сбоку.*

В первый раз Claude попросит войти. Вход проходит в браузере: вы подтверждаете, что это вы, под той же учётной
записью, на которой оплачена подписка, и возвращаетесь в VS Code.

### 5. Напишите первое сообщение

Во вкладке Claude напишите по-русски:

```
Привет. Создай в этой папке файл hello.txt и напиши в нём, что ты умеешь делать, в пяти строках.
```

![Вкладка Claude Code с первым сообщением в поле ввода; внизу справа — режим Manual и оранжевая стрелка отправки](/media/shots/vscode-vkladka-claude.png)

*Сообщение вписано в поле внизу. Отправьте его оранжевой стрелкой справа или клавишей Enter.*

Claude спросит разрешения создать файл:

![Вопрос Claude «Allow write to hello.txt?» с тремя ответами: Yes, Yes allow all edits this session и No](/media/shots/vscode-razreshenie.png)

*Над вопросом — что он собирается записать в файл. Нажмите «Yes». Что значат остальные ответы — в материале
[[chto-on-sprashivaet|Что он спрашивает и что отвечать]].*

Слева в списке файлов появится `hello.txt` — откройте его.

![Слева в папке first появился файл hello.txt; справа Claude пишет, что файл создан, и перечисляет пять строк](/media/shots/vscode-gotovo.png)

*Файл появился слева, а Claude коротко пересказал, что в нём написал.*

Если файл появился, всё установлено.

## Если не получилось

- **Дополнения нет в поиске.** Обновите VS Code: Claude Code не ставится в старые версии.
- **Вход не проходит.** Проверьте, что в браузере вы вошли в ту учётную запись, на которой оплачена подписка.
- **Claude не отвечает или пишет об ошибке соединения.** Не включено специальное программное обеспечение, без
  которого сервис не работает из России, — см. [[kakoy-instrument-vzyat|Какой инструмент взять]].
- **Claude отвечает, что лимит исчерпан,** хотя вы только начали. Вход выполнен под учётной записью без подписки.
- **Не понимаете, о чём он спрашивает.** Так и напишите: «объясни проще, что ты хочешь сделать и зачем».
