## Что получится

Значок в углу экрана. Нажали — Claude, сайт `claude.ai` и Claude Code в VS Code работают. Банки, госуслуги, почта и видео при этом идут напрямую, как без программы: их ничего не касается.

Это моя программа — я сделал её для себя, когда надоело включать и выключать всё подряд ради одного сервиса. Она бесплатная, код открыт: [github.com/cookiespooky/proxy-tunnel](https://github.com/cookiespooky/proxy-tunnel).

## Чем это удобно

- **Только то, что нужно.** Через сервер идут Claude и сайты из вашего списка. Остальное — напрямую.
- **Всегда один адрес.** Claude видит вас с адреса вашего сервера — одного и того же каждый день.
- **Сервер ваш.** Программа соединяет компьютер с сервером, который вы арендовали сами. Чужих серверов в цепочке нет.
- **Пароль не хранится.** Он нужен один раз, при первой настройке, и вводится только в окно программы.

## Что понадобится

- компьютер с macOS 13 или новее либо с Windows 10 или 11;
- свой сервер за границей с Ubuntu или Debian. Если сервера нет — в программе есть кнопка «Арендовать сервер». Аренда платная, у хостинга; после неё он пришлёт адрес сервера (несколько цифр через точку) и пароль от пользователя `root`.

## Как поставить

Проще всего — попросить нейросеть провести вас по шагам. Скопируйте ей:

```text
Прочитай инструкцию https://raw.githubusercontent.com/cookiespooky/proxy-tunnel/main/AI-SETUP.md
и помоги мне по ней установить и настроить Proxy Tunnel. Веди по одному шагу и жди моего ответа.
```

Пароль от сервера нейросети не присылайте — он вводится только в окно программы.

Сами, коротко:

1. Скачайте программу со [страницы выпусков](https://github.com/cookiespooky/proxy-tunnel/releases/latest): `ProxyTunnel-mac.dmg` для Mac, `ProxyTunnel-windows.exe` для Windows.
2. **Mac:** перетащите значок в «Программы». Первый запуск — правой кнопкой по программе → «Открыть» → «Открыть». **Windows:** запустите файл; если Windows предупредит — «Подробнее» → «Выполнить в любом случае».
3. В окне настроек впишите адрес сервера, логин `root` и пароль, оставьте галочку «Создать ключ для входа».
4. Нажмите «Настроить сервер» и подождите минуту-две, пока все пункты станут зелёными.

Подробная инструкция — в [README программы](https://github.com/cookiespooky/proxy-tunnel#readme).

## Как пользоваться

- **Включить:** значок программы → верхняя карточка «Туннель выключен». Зелёный значок и «Claude — через туннель» — работает.
- **После включения закройте и снова откройте VS Code и браузер**, если они были открыты: иначе они продолжают ходить по-старому.
- При каждом запуске программа начинает выключенной — включайте, когда садитесь работать с Claude.

В списке у новых установок уже есть ChatGPT и Gemini — если пользуетесь ими, они пойдут тем же путём.

## Если не получилось

- **Под красным пунктом в окне программы** написано, что случилось и что сделать.
- **«Сервер отклонил подключение» сразу после настройки** — подождите полминуты и нажмите «Проверить».
- **Claude Code перестал отвечать** — проверьте, что программа запущена и туннель включён. Если выключили программу, перезапустите VS Code.
- **Программа закрылась** — запустите снова: при запуске она сама наводит порядок.
