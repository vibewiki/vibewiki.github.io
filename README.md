# Вайбкодинг с нуля

Открытый курс в формате вики для тех, кто не программист: от оплаты и установки до своего сайта, приложения и бота.
Сайт собирается движком [Notepub](https://github.com/cookiespooky/notepub) из папки `content/`.

**Состояние на 2026-10-11:** написаны все девять ступеней (двадцать девять материалов; пять последних — о VS Code и о подключении почты, календарей и канала — без даты проверки, пока шаги не пройдены руками). Репозиторий —
`github.com/vibewiki/vibecourse`, сайт — GitHub Pages: `https://vibewiki.github.io/vibecourse/`. **Пуш в `main`
публикует сайт** (`.github/workflows/pages.yml`); на пулл-реквесте та же сборка идёт как проверка, без выкладки.

Тексты — по лицензии CC BY-SA 4.0 (`LICENSE`): их можно использовать и переделывать, сохраняя подпись автора и
ту же лицензию.

## Команды

```bash
scripts/preview.sh              # собрать и открыть у себя: http://127.0.0.1:8087/
scripts/preview.sh --build-only # только собрать в dist-dev/
scripts/build.sh                # сборка для выкладки в dist/
python3 scripts/check.py        # проверка материалов без сборки (секунда)
```

Сборке нужен `notepub`: скрипт берёт `.bin/notepub`, затем `../site/.bin/notepub`, затем из `PATH`, иначе ставит
его через Go. Ничего не коммитится и не публикуется само.

## Как устроено

| путь | что |
|---|---|
| `content/home.md` | главная: вводный абзац (`lead`) и блок «Кто это пишет»; остальное на ней — в `theme/templates/home.html` |
| `theme/templates/home.html` | главная без бокового меню: первый экран со снимком, «что получится», девять ступеней карточками (материалы — из коллекций), блок «После курса». Строки «что выйдет» у ступеней вписаны руками, как названия в `sidebar.html` |
| `content/after-course.md` | «После курса» (`/posle-kursa/`) — оффер: разбор, сделать вместе, Life OS, следующий курс. Цен в нём нет: суммы не утверждены. Ссылки на него — в шапке, внизу бокового меню, на главной и в конце материала «Когда звать человека»; адрес — `after_slug` в обоих `config*.yaml` |
| `media/shots/` | снимки экрана; сборка копирует `media/` в `dist/media/`. В тексте — `![что на снимке](/media/shots/имя.png)`, строка курсивом сразу под ним печатается подписью |
| `content/add-material.md` | страница «Как добавить свой материал» — на неё ведёт ссылка в шапке; то же, что `CONTRIBUTING.md`, для читателя сайта: править вместе |
| `content/NN-имя/*.md` | материалы ступени; папка — только для порядка на диске, ступень задаёт поле `step` |
| `rules.yaml` | типы страниц, разрешённые поля, по коллекции на ступень |
| `theme/templates/partials/sidebar.html` | боковое меню: слева на широком экране, в ящике справа на узком |
| `theme/assets/wiki.css`, `wiki.js` | раскладка и ящик; цвета и шрифты — `tokens.css`, копия файла сайта antonlozhkin.ru |
| `scripts/check.py` | у каждого материала есть подпись, ступень и место в ней; адреса не повторяются |

**Снимки.** Страница, калькулятор и форма — настоящий результат запросов курса, отправленных в Claude Code в чистом
профиле VS Code (фото — `media/shots/random-person.jpeg` с thispersondoesnotexist.com, лицо сгенерировано; переименовано в `photo.jpg`), сняты в Chrome;
окна VS Code — в отдельном чистом профиле на демо-папках. Блок «Recent» на стартовой странице закрашен: macOS отдаёт
в него недавние папки владельца компьютера. Ширина — до 1600 точек. На снимке не должно быть
ключей, токенов, закрытых адресов календаря и чужих имён — их закрашивают до того, как файл попадёт в `media/`.

**Подпись автора обязательна.** Под каждым материалом печатаются `author` со ссылкой `author_url`, дата `checked`
и инструмент `tool`. Без `author` и `author_url` сборка не проходит.

**Новая ступень — три правки, которые ничто не сверяет между собой:** коллекция `step_N` в `rules.yaml`, блок в
`sidebar.html` и число в `STEPS` у `scripts/check.py`. Движок не умеет циклов по числам, поэтому названия ступеней
вписаны в `sidebar.html` руками.

**Ссылка на другой материал — вики-ссылкой:** `[[adres-materiala|текст ссылки]]`. Сайт живёт по адресу с путём
(`/vibecourse`), поэтому обычная ссылка от корня `/adres/` на нём не откроется, а сборка этого не заметит.

**`NOTEPUB_REF` записан дважды** — в `scripts/build.sh` и в `.github/workflows/pages.yml`; менять вместе.

**Имя файла — английское, адрес — транслитом:** `content/01-start/what-you-need.md` со `slug: chto-ponadobitsya`.
Адрес после публикации не меняется.

Как добавить свой материал — [CONTRIBUTING.md](CONTRIBUTING.md).
